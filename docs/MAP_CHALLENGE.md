# تحدّي الخريطة — التشغيل والنشر

طُوّرت النسخة وجُرّبت محليًا على فرع `feature/saudi-map-minute`. اعتمد المالك التجربة والألوان وأذن بالنشر الرسمي في ٢٧ سبتمبر ٢٠٢٦. الدفع إلى `main` يشغّل التحقق، ثم ترحيلات D1 الإضافية، ثم النشر على [الموقع الرسمي](https://jdsc.ahmedbahathiq.com). تُجرّب التعديلات التالية محليًا ويُطلب اعتماد نشرها عند جاهزيتها.

## التشغيل

يتطلب Node.js 24. من مجلد المشروع:

```sh
npm ci
npm run map:db
npm run map:dev
```

المعاينة: `http://127.0.0.1:8790/`. قاعدة D1 محلية في `.wrangler/map-preview`؛ لا تستخدم `--remote`. الواجهة مبنية مسبقًا؛ بعد تعديلها شغّل `npm run build` وحدّث الصفحة. كود الخادم يعاد تحميله تلقائيًا.

## القواعد والبيانات

- اسم مطلوب حتى ٤٨ حرفًا، مع اقتراح اسم ثنائي أو ثلاثي. تُحفظ آخر قيمة محليًا لتسهيل الجولة القادمة. الاسم والدرجة عامّان بعد إكمال الجولة.
- المقارنة بعد NFC، توحيد المسافات، إزالة التطويل والتشكيل العربي، وتوحيد حالة الإنجليزية. تبقى الهمزات والأحرف المختلفة متميزة. الاسم ليس تسجيل دخول؛ التطابق يدمج أفضل نتيجة.
- ٦٠ ثانية من وقت الخادم، +١٠ للصحيح، صفر للخطأ، مدينة واحدة مرة واحدة، حد أعلى ١٠٠. الاختيار يثبت فورًا، وتفسير الإجابة بعد الجولة.
- الأفضل نقاطًا ثم الأقل زمنًا إلى آخر إجابة صحيحة. صفر النقاط لا يُفاضل بالسرعة. التطابق الكامل يشترك في الترتيب وتُعرض الأسماء بالأسبق تحقيقًا.
- انتهاء المهلة أو الإجابة عن المدن العشر يكمل الجولة. قراءة الحالة أو الإحصاءات تُنهي الجولات المتروكة المنتهية. لا تُقبل إجابة جديدة عند وقت النهاية أو بعده.
- الرموز عشوائية ويُحفظ تجزئتها فقط. جميع النقاط والمؤقت والأسئلة تُحسب على الخادم. إعادة الطلب لا تضاعف الإجابة أو التصويت.
- عند فقد رد محفوظ، إعادة الطلب تستعيده حتى بعد المهلة. إذا وصل الطلب أول مرة بعد المهلة لا يحتسب. لا يُوقف انقطاع الشبكة الساعة.
- اسم الفعالية الجديدة هو `EVENT_ID:map-v1`. لا تختلط مع جولات ٠–٣ القديمة. الترحيل إضافي، وتبقى واجهات وممرات الجولات القديمة متاحة.
- المستودع مفتوح المصدر؛ النشاط للتعلّم والمنافسة الودية، ولا يحقق هوية الطالب أو يمنع معرفة الحلول من الكود.

## المسارات والواجهات

الواجهة: `/` للاسم، `/map` للخريطة، `/map-result` للبطاقة والمراجعة، `/results` للإحصاءات، `/results?tab=leaderboard` للترتيب. أضف `display=1` لشاشة البوث. الجولات القديمة `/quiz` و`/result`، وإحصاءاتها `/legacy-results`.

جميع طلبات الجولة تحمل `Authorization: Bearer <UUIDv4>` في الترويسة؛ لا تضَع الرمز في الرابط. طلبات POST من الموقع نفسه، بجسم JSON صغير.

| المسار بعد `/api/map/` | الطريقة | الغرض |
|---|---|---|
| `round` | POST `{name}` | إنشاء الجولة أو استرجاعها دون تغيير الاسم أو الوقت |
| `round` | GET | استعادة الجولة والتوقيت والإجابات المحفوظة |
| `city` | POST `{cityId}` | فتح سؤال المدينة؛ لا يمكن تبديل سؤال مفتوح |
| `answer` | POST `{questionId,selected}` | حفظ الخيار ٠–٢ مرة واحدة |
| `finish` | POST `{}` | مزامنة الإكمال؛ لا ينهي مبكرًا قبل الشروط |
| `vote` | POST `{city}` | تصويت اختياري بعد الجولة؛ أول اختيار ثابت |
| `stats`, `leaderboard` | GET | ملخص الإحصاءات وأفضل عشرة أسماء |

تتضمن حالة الجولة الاسم، `score` و`tier`، `startedAt/expiresAt/serverNow` بالميلي ثانية، السؤال النشط دون الحل، المدن المجاب عنها، والمراجعة بعد الإكمال وأفضل ترتيب للاسم. الاستجابة الشخصية `no-store`؛ الملخص العام مخبأ خمس ثوانٍ. تحديث الواجهة العامة كل ٣٠ ثانية، والبوث كل خمس ثوانٍ حين تكون الصفحة ظاهرة.

## التصدير والاختبارات

```sh
npm test
npm run build
npm run export:map -- --local --staging
```

CSV يضم صفًا لكل إجابة في جولة مكتملة، أو صفًا فارغ الإجابة للجولة المنتهية دون إجابات. **لا تجمع النقاط عبر الصفوف** لأنها تتكرر مع كل إجابة؛ اجمع حسب `participation_id`. زمن الجولة بالميلي ثانية. لا يحتوي CSV رمز الدخول للجولة. الأسماء معروضة ومخزنة؛ حافظ على ملفات التصدير خارج GitHub.

قبل أي نشر لاحق: موافقة المالك على المعاينة، مراجعة أسئلة المدن، اختبارات الهاتف والبوث والتنزيل، ثم ترحيل الإنتاج ونشر الفرع المعتمد. اختبارات SQLite المحلية ليست ضمانًا لسعة Cloudflare أو لمقاومة الغش.

نتائج التحقق الحالي: [سجل الاختبارات المحلية](MAP_VERIFICATION.md).
